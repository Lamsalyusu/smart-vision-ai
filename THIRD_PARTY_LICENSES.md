# Third-Party Dependencies and Intellectual Property Notice

This document provides legal and licensing disclosures for all third-party software, pre-trained weights, models, and dataset sources utilized by the **SmartVision AI** project.

## Vendor Intellectual Property Policy Alignment

This repository strictly separates proprietary author-created assets from open-source foundational libraries:

- **Author-Owned & Proprietary Assets**:
  - The custom 7.9M parameter YOLO model architecture and trained model weights (`legacy_django/backend/ml_model/weights/best_weights.weights.h5`), stored via Git LFS.
  - All 10 3D GLB model files (`public/models/*.glb`), which were procedurally generated by the author specifically for this application (`SmartVisionAI Procedural Mesh`).
  - All backend, pipeline, tracking, spatial fusion, scene graph, and UI application code.
- **Foundation & Permissive Third-Party Assets (For Vendor Evaluation)**:
  - Public community training datasets sourced via Roboflow Universe under Creative Commons Attribution 4.0 International (CC BY 4.0).
  - Intel MiDaS v2.1 Small model architecture used under the MIT License for monocular depth estimation.
  - Standard open-source frameworks (Django under BSD-3, TensorFlow under Apache 2.0, PyTorch under BSD, Three.js under MIT).

## 1. Machine Learning Models & Architectures

### Custom YOLO Model
* **Architecture**: CSPDarknet backbone + SPPF + FPN Neck (`legacy_django/backend/ml_model/model.py`).
* **Implementation**: Developed in TensorFlow/Keras 2.x by Yuyutsu Lamsal.
* **Weights**: Trained by the author on Google Colab (`legacy_django/backend/ml_model/weights/best_weights.weights.h5`, 32 MB, stored via Git LFS).
* **License**: MIT License (project author).
* **Stored via**: Git LFS (`.gitattributes`: `*.h5 filter=lfs diff=lfs merge=lfs -text`).

### MiDaS (Monocular Depth Estimation)
* **Author / Organization**: Intel Intelligent Systems Lab (ISL) / René Ranftl et al.
* **Repository**: `https://github.com/isl-org/MiDaS`
* **Model**: MiDaS v2.1 Small
* **License**: MIT License
* **Terms**: Free for research and commercial evaluation.
* **Used by**: `legacy_django/backend/ml_model/depth_estimation.py` (optional; loaded via TorchHub only when PyTorch is installed).

### TripoSR (Single-Image 3D Mesh Reconstruction)
* **Authors / Organization**: Stability AI & Tripo AI
* **Repository**: `https://github.com/VAST-AI-Research/TripoSR`
* **License**: MIT License
* **Used by**: `TRIPOSR_API_URL` integration in `legacy_django/backendcore/settings.py`.
