About MiDaS Depth Estimation

MiDaS (Monocular Depth Estimation in the Wild) predicts relative depth from a single RGB image. The cropped detection is fed through the MiDaS v3 DPT-Large model, producing a depth map where each pixel gets a depth value. This depth map is then back-projected into 3D coordinates using the camera intrinsics, creating a colored point cloud that can be viewed and rotated in 3D space.
